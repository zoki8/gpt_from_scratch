# GPT from scratch

A small character-level GPT written from scratch in PyTorch and trained on Shakespeare. The project builds up one piece at a time: a tokenizer first, then a bigram model, self-attention, multi-head attention, feed-forward layers, transformer blocks with residual connections and LayerNorm, and finally dropout and a bigger model trained on a GPU.

## Sample

Generated by the trained model (4.8M parameters) from the prompt `ROMEO:` at temperature 0.8:

```
ROMEO:
My lord and fetch my blood!

CAMILLO:
But thou find to live sorrow'st thou doling pay.

DUKE OF AUMERLE:
'Tis no lady soul, but my life so prince;
One will be tear my company of thy penish'd;
Never state of Warwick, which hath not the seat of thy and care
```

The model writes one character at a time. None of these lines appear in the training text.

## Results

Validation loss (cross-entropy per character, lower is better) on the last 10% of the text, which the model never trains on:

| Model | Parameters | Val loss |
|---|---:|---:|
| Bigram (lookup table) | 4K | 2.49 |
| 1 attention head | 7.5K | 2.44 |
| 4 attention heads | 7.5K | 2.32 |
| + feed-forward | 16K | 2.26 |
| 3 blocks, residual connections, LayerNorm | 42K | 2.16 |
| 4 blocks, 128 embd, 64 context, dropout 0.1 | 0.8M | 1.56 |
| **6 blocks, 256 embd, 128 context, dropout 0.2** | **4.8M** | **1.53** |

A loss of 1.53 means the model gives the correct next character about 22% probability on average (e^-1.53), compared with 1.5% for random guessing among 65 characters (ln 65 = 4.17).

The last model trains in about 14 minutes on an NVIDIA RTX 2050 (4 GB). Training loss ends at 1.26, so the model has started to memorise the 1 MB training text. A bigger model would need more data to do better.

## Files

| File | What it does |
|---|---|
| `tokenizer.py` | `CharTokenizer`: maps each of the 65 characters in the text to a number and back |
| `data.py` | Loads `data/input.txt`, splits it 90/10 into train and validation, and samples random batches with `get_batch` |
| `model.py` | `Head`, `MultiHeadAttention`, `FeedForward`, `Block`, the original `BigramModel`, and `AttentionModel` (the GPT) |
| `train.py` | Hyperparameters, the training loop, loss estimation, and saving the model to `model.pt` |
| `generate.py` | Loads `model.pt` and writes new text from a prompt |
| `attention_playground.py` | Small experiment showing how a triangular matrix averages past tokens, the trick behind masked attention |

## Model

```
characters → token embedding + position embedding
           → 6 × Block [ x + MultiHeadAttention(LayerNorm(x)),  x + FeedForward(LayerNorm(x)) ]
           → LayerNorm → Linear → scores for the next character
```

- Masked self-attention: each position only sees earlier positions.
- 4 heads per block, each with its own query, key and value.
- Feed-forward: Linear (256 → 1024), ReLU, Linear (1024 → 256).
- Dropout 0.2 on attention weights and on each block's outputs.
- AdamW, learning rate 3e-4, batch of 64 sequences of 128 characters, 5000 steps.

## Running it

Set up the environment:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

`requirements.txt` installs the CPU build of PyTorch. To train on an NVIDIA GPU, install a CUDA build that matches your driver, for example:

```bash
pip install torch --index-url https://download.pytorch.org/whl/cu130
```

Train (uses the GPU automatically if PyTorch can see one, and saves `model.pt`):

```bash
python train.py
```

Generate text from the saved model:

```bash
python generate.py "ROMEO:" 400 0.8
```

The three arguments are the prompt, the number of characters to write, and the temperature. Lower temperature (0.5) gives safer, more repetitive text, and higher temperature (1.5) gives more varied but messier text. Without arguments it starts from a new line and writes 500 characters at temperature 1.0. The prompt can only use characters that appear in the training text.

`model.pt` is not in the repository (`*.pt` is in `.gitignore`), so run `train.py` once before `generate.py`.

## Data

`data/input.txt` is the Tiny Shakespeare dataset: about 1.1 million characters from Shakespeare's plays.
